# Dynamic Online News Portal

## Project Overview
The Dynamic Online News Portal is a web-based application designed to display news articles across different categories.

## Objectives
- Provide an interactive platform for reading news.
- Organize news articles into categories.
- Display news content through a user-friendly interface.
- Store and manage news data using MySQL.

## Technologies Used
- Core Java
- MySQL
- HTML
- CSS
- JavaScript (if used)

## Key Features
- News categories
- Article display
- User-friendly interface
- Database integration

## Project Purpose
Developed as an academic project to demonstrate Java programming, database management, and web development skills.
